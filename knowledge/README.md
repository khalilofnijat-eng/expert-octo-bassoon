# knowledge/

Onaylı ve sürümlü bilgi tabanı kaynakları burada tutulur (işletme kuralları, ürün/uyumluluk bilgisi, onaylı cevap örnekleri). Yalnızca sahibin onayından geçmiş bilgi girer; öğrenme adayları onaylanana kadar buraya işlenmez ve her değişiklik sabit değerlendirme senaryolarından geçer ([../docs/DECISIONS.md](../docs/DECISIONS.md) D-004, D-005). Henüz içerik yok.
