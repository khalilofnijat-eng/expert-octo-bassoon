# tests/

Otomatik testler ve bilgi tabanı / prompt / model değişikliklerinde çalıştırılacak sabit değerlendirme senaryoları burada tutulur. Sonuçlar [../docs/TEST_REPORT.md](../docs/TEST_REPORT.md)'de, sentetik ve gerçek sistem testleri ayrı raporlanır. `tests/fixtures/` yalnızca **sentetik** test verisi (görsel, `.jsonl`, `.csv`) içerebilir; `.gitignore` bu uzantıları yalnızca orada kabul eder. Gerçek müşteri konuşması, gerçek ürün fotoğrafı veya işletme verisi buraya girmez. Henüz test yok.
