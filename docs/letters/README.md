# Mektuplar hakkında (Türkçe)

Bu klasördeki iki mektup, Avito destek ekibine ve poisk.vin destek ekibine gönderilmek üzere hazırlanmıştır (her biri Rusça metin + altında Türkçe çevirisiyle).

- `avito_support_ru.md` mektubunu Avito kişisel hesabınızdaki (личный кабинет) destek formundan gönderin.
- `poisk_vin_ru.md` mektubunu poisk.vin sitesindeki iletişim kanalından gönderin (kanalı zaten biliyorsunuz).
- Gönderdikten sonra gelen yanıtları (ekran görüntüsü veya metin olarak) mutlaka saklayın.
- Yanıtları aldığınızda, içeriğini Ana Ajan'a (Main Agent) iletin ki proje bu bilgilere göre ilerlesin.
