# website-kickoff — E-ticaret sitesi projesinin başlangıç dosyaları

Bu klasör, Avito müşteri asistanından **ayrı** yürütülecek oto parça e-ticaret sitesi projesinin başlangıç paketidir; siteyi kurmaz, yeni oturumu başlatmak için hazırlanmıştır ve iki proje ileride birleştirilecektir. Kullanımı: yeni bir **özel (private)** GitHub deposu açıp bu klasördeki [KICKOFF_PROMPT.md](KICKOFF_PROMPT.md), [CLAUDE.md](CLAUDE.md) ve [SKILLS.md](SKILLS.md) dosyalarını deponun **köküne** kopyalayın (Claude Code `CLAUDE.md`'yi kökte otomatik okur), ardından o depoda yeni bir Claude Code oturumu açıp `KICKOFF_PROMPT.md`'nin içeriğini ilk mesaj olarak aynen yapıştırın. Depo hazırlamadan başlamak isterseniz yeni bir oturum açıp yalnızca `KICKOFF_PROMPT.md`'yi yapıştırmanız da yeterlidir; talimat, diğer iki dosyanın bu depodaki `website-kickoff/` klasöründen alınmasını ister.
